## 🚀 Features

- 🔷 **Flow-Based Visual System**  
  Converts messy Blueprint graphs into clean, structured flows

- 🧱 **Block-Style Logic**  
  Inspired by block coding to improve clarity and usability

- ⚡ **Faster Development**  
  Build logic quicker with simplified node interactions

- 🧠 **Improved Readability**  
  Reduce “spaghetti graphs” and make systems easier to understand

- 🔄 **Seamless Integration**  
  Works alongside Unreal Engine’s existing Blueprint system

## 📦 Installation

1. Download the latest release  
2. Extract into your Unreal Engine `Plugins` folder  
3. Enable **NodeFlow** in the Plugins menu  
4. Restart Unreal Engine  

---

## 🛠️ Usage

- Open any Blueprint  
- Enable NodeFlow mode  
- Build using simplified flow-based nodes  

---

## 🎯 Goal

NodeFlow aims to bridge the gap between:

- 🧠 Beginner-friendly block coding  
- ⚙️ Advanced Unreal Engine Blueprint systems  

So developers can:
- Learn faster  
- Build faster  
- Understand systems more easily

## 💡 Why NodeFlow?

Blueprints are powerful—but as projects grow, they often become hard to manage and visually overwhelming.

NodeFlow fixes that by making Blueprint scripting:
- Cleaner  
- More structured  
- More intuitive
